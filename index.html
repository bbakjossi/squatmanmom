대기 중
  • 폰을 삼각대나 받침대에 세워 고정하고, 머리부터 발끝까지 화면에 담으세요.
  • 연결되면 이 화면을 켜 둔 채로 두세요. 화면이 꺼지거나 다른 앱으로 넘어가면 전송이 끊깁니다.
  • 분석 PC와 폰이 같은 Wi-Fi에 있으면 연결이 가장 안정적입니다.

스쿼트 다중 카메라 분석기

폰 카메라를 QR로 연결해 측면과 정면(후면)을 동시에 촬영하고, 한 번의 스쿼트에서 시상면과 전두면 각도를 함께 얻습니다.

준비 중

카메라 연결

QR을 폰 카메라로 스캔하면 브라우저가 열립니다. 폰에서 "카메라 시작 및 연결"을 누르면 영상이 이 화면으로 전송됩니다. 필요한 카메라만 연결해도 됩니다.

데이터

시작하기
  1. 이 파일을 인터넷에 올려 https 주소를 만듭니다(아래 "호스팅 방법").
  2. 그 주소로 PC에서 이 페이지를 열고, 위 입력칸에 같은 주소를 넣습니다.
  3. 폰으로 QR을 스캔해 연결합니다. 측면 폰은 몸의 옆면과 수직으로, 정면 폰은 정면에 둡니다.
  4. 정자세로 서서 "정자세 보정"을 누른 뒤 "측정 시작"을 누릅니다.
호스팅 방법

폰은 https 주소에서만 카메라를 쓸 수 있어서, PC에 저장된 파일을 폰에서 열 수 없습니다. 무료 정적 호스팅에 이 HTML 파일 하나만 올리면 됩니다.

  • GitHub Pages: 저장소를 만들고 파일을 올린 뒤 Settings의 Pages에서 배포를 켭니다.
  • Netlify나 Vercel: 파일(또는 폴더)을 끌어다 놓아 배포합니다.

배포된 파일 주소(예: https://아이디.github.io/저장소/squat-multicam-lab.html)를 위의 주소 칸에 넣으세요.

각도 정의
  • 무릎 굴곡: 180도 - 엉덩이, 무릎, 발목이 이루는 각
  • 고관절 굴곡: 180도 - 어깨, 엉덩이, 무릎이 이루는 각
  • 발목 배측굴곡: 90도 - 무릎, 발목, 발끝이 이루는 각
  • 몸통, 정강이 기울기: 측면 영상에서 수직선과 이루는 각 (앞쪽이 +)
  • FPPA: 정면(후면) 영상의 무릎 외반(+)과 내반(-) 각
  • FPPA와 폭비는 해당 반복 구간에서의 최대 외반, 최대 굴곡 시점의 값입니다.
한계

각 폰의 영상은 네트워크를 거쳐 오기 때문에 카메라 간 시간 차이(수십~수백 ms)가 있습니다. 이 앱은 반복 구간 안의 최대값과 최대 굴곡 시점 값을 쓰므로 영향이 작지만, 프레임 단위 동기 분석에는 적합하지 않습니다. 카메라별 각도는 독립적으로 추정되며 3D 삼각측량은 하지 않습니다. 분석 PC의 탭은 항상 화면에 보이게 두세요. 탭이 가려지면 처리가 느려집니다.
